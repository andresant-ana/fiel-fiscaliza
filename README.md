# Fiel Fiscaliza

Projeto independente, comunitário e sem fins lucrativos para ajudar corinthianos a compreender, acompanhar, preservar e fiscalizar a vida institucional do Sport Club Corinthians Paulista.

> Projeto em fase de especificação e documentação inicial.

O Fiel Fiscaliza não representa oficialmente o Sport Club Corinthians Paulista, a Gaviões da Fiel ou qualquer grupo político do clube.
